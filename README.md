# Dota 2 assistant

**Автор:** Морозов Кирилл Сергеевич

Учебный ИИ-помощник для нашей команды в любительском турнире по Dota 2 (Captains Mode).

Выгружает из [OpenDota API](https://docs.opendota.com/) данные по нашим игрокам, соперникам по группе и
текущему патчу, строит отчёты и показывает всё на **локальном сайте** с помощником для живого драфта.

## Быстрый старт

```bash
./gradlew run        # скачать/докачать данные (≈140 запросов к OpenDota, пара минут)
./gradlew web        # сайт: http://127.0.0.1:8070
```

Перед игрой: `./gradlew run`, затем на сайте кнопка «Перечитать данные» (или перезапуск `web`).

## Запуск

Нужен JDK 21. Gradle-wrapper в репозитории, Gradle ставить не нужно.

```bash
./gradlew run                                   # докачать то, чего нет
./gradlew run --args="--refresh"                # перекачать всё
./gradlew run --args="--only 138244651"         # один игрок
./gradlew run --args="--no-meta"                # без данных по патчу
./gradlew run --args="--no-league"              # без матчей лиги
./gradlew run --args="--no-stratz"              # без линии и матчапов из STRATZ
./gradlew analyze                               # отчёты в analysis/ из data/
./gradlew analyze --args="--date 2026-10-14"    # отчёты на дату (давность матчей считается от неё)
./gradlew web                                   # сайт на http://127.0.0.1:8070 (--args="--port 8080")
./gradlew draftBacktest                         # проверка прогнозов драфта на матчах группы
./gradlew build                                 # сборка и тесты
```

На Windows вместо `./gradlew` используйте `gradlew.bat`.

Опции меты: `--meta-window <n>` — сколько последних match_id брать в выборку (по умолчанию 1 000 000,
это около 250 тыс. матчей Legend+ за ~15 часов); `--meta-min-rank <n>` — минимальный средний `rank_tier`
матча (по умолчанию 50 = Legend).

Если есть ключ OpenDota, задайте переменную окружения `OPENDOTA_API_KEY`. Без ключа лимит
60 запросов в минуту и 3000 в день. Полный прогон для 10 игроков занимает около 100 запросов.

Статистика линии берётся из STRATZ: нужен бесплатный токен (stratz.com/api → «Мои токены», после входа через
Steam). Положите его в `.env` строкой `STRATZ_TOKEN=…` или задайте переменной окружения. Без токена этот шаг
пропускается, а вкладка «Контрпики» показывает только «по игре». Выгрузка — 127 запросов, около 4 минут.

    wl.json        /players/{id}/wl?significant=0         победы/поражения, сверка с matches.json
    matches.json   /players/{id}/matches?significant=0&project=…   все матчи, 56 полей
    heroes.json    /players/{id}/heroes                   по героям: свои игры, с ним, против него
    peers.json     /players/{id}/peers                    с кем играл
    counts.json    /players/{id}/counts                   разбивки по lane_role, game_mode, patch…
    totals.json    /players/{id}/totals                   суммы по метрикам
    ratings.json   /players/{id}/ratings                  история rank_tier
    rankings.json  /players/{id}/rankings                 перцентиль игрока на героях
data/raw/league/{league_id}/
    match_ids.json      /leagues/{id}/matchIds — перекачивается каждый запуск (растёт по ходу турнира)
    matches/{id}.json   /matches/{id} — матчи текущего сезона (с league.since), с драфтом
data/meta/{patch}/
    hero_stats.json     /heroStats            пики/победы по рангам, pro pick/ban, тренд за неделю
    lane_roles.json     /scenarios/laneRoles  винрейт героя по линии и длительности
    hero_winrate.json   /explorer  винрейт героев в выборке патча
    hero_synergy.json   /explorer  пары героев в одной команде
    hero_counters.json  /explorer  герой против героя
    hero_positions.json /explorer  позиция 1–5 героя в разобранных матчах патча
    _sample.json        параметры выборки
data/raw/stratz/lanes/{неделя}/
    {hero_id}.json      STRATZ GraphQL heroStats: laneOutcome по позициям 1–5 за 4 недели (исход линии против каждого

    _sample.json        недели и ранги выборки

## Сайт

`./gradlew web` → http://127.0.0.1:8070 (только этот компьютер). К OpenDota сайт не обращается: читает `data/`,
`config/players.yaml` и ручные планы из `analysis/`. Кнопка «Перечитать данные» подхватывает изменения без перезапуска.

| Страница | Что на ней |
|---|---|
| Главная | следующий соперник (`league.next_opponent`), группа, наш состав, предупреждения о данных |
| Команда / Игрок | состав, где реально играют, сыгранность; карточка игрока — наша или соперника |
| Наш драфт | план драфта (`draft_plan.md`) + пулы, связки, неудобные герои, кандидаты в баны |
| Турнир / Группа | наши матчи с драфтами по ходам; все матчи группы |
| Соперник | план на игру (`game_plan.md`), угрозы, их баны, ответы из наших пулов, их турнир, состав |
| Мета / Методика | мета патча по позициям, про-сцена, связки, контрпики; как считаются оценки |
| **Драфт** | живой драфт Captains Mode (ниже) |

### Живой драфт

Экран устроен как драфт в клиенте: слева наши 5 слотов, справа их 5, в центре поиск и подсказки на текущий ход,
сверху лента 24 ходов, снизу сетка портретов героев. Вносить ходы: поиск героя (имя, начало имени, инициалы `WK`,
сокращения и их начало: `вк`, `леш`, `кунк`), ↑↓ по списку вариантов и Enter, или клик по герою. Порядок ходов CM
подставляется сам (как в 39 матчах нашей лиги). Пересчёт после хода ≈ 10–150 мс.

- **Лента 24 ходов** с иконками: клик по сделанному ходу — исправить его, не трогая остальные.
- **Защита от ошибок ввода.** Наш бан героя из пула нашего игрока и наш пик героя не из наших пулов вносятся только
  после подтверждения (ещё раз Enter или клик): так ловится ход, внесённый не той стороне.
- **Слот игрока**: ранг, ссылки на Dotabuff / OpenDota / STRATZ, герои за последние 14 дней (🔥 — новый, не из его
  топа; 👥 — играл в пати со своей командой), портрет героя, если он уже выбран, с вероятностью и альтернативой.
  Пока их игрок без героя — его вероятные герои. Список в слоте — назначить герой игроку вручную.
- **Клик по нику** открывает карточку игрока сбоку: «чем играет сейчас» (14 дней, 2 месяца, с командой, Турбо
  отдельно), «всегда может достать» (умение по всей истории), последние матчи с размером пати и тем, кто из своих был.
- **Что они возьмут** — шанс, что они возьмут героя до конца драфта, с главными причинами (остальные — по наведению).
- **Что они забанят у нас** — шанс, что наш герой уйдёт в бан до конца их банов: наши герои у наших игроков без
  героя плюс их привычка банить в турнире (4 из 4 → 80%).
- **Кого нам банить и кого брать** — с «пик-отказом» (герой из их топа, который есть и у нас).
- На каждом ходу первой и с рамкой стоит нужная панель; панели, ходы которых закончились, прячутся.
- **Итог драфта**: линии по позициям с преимуществом по встречным парам героев, их самые опасные герои и кнопка
  «Скопировать текстом» (для чата команды).

Драфт хранится в браузере и в адресе страницы (`#first=us&heroes=…&assign=…`) — ссылкой можно поделиться.

Бэктест (`./gradlew draftBacktest`) на 6 матчах группы (60 пиков), проверяемый матч исключается из истории, а свежая
форма игроков (2 месяца, игры с командой) считается только по играм до него:

| | Модель | Бейзлайн |
|---|---|---|
| Реальный пик в топ-5 / топ-10 | 47% / 67% | 32% / 47% («частые герои игроков за год и патч») |
| Их реальные баны в нашем топ-7 на первом ходу | 32% | 21% («их частые баны в турнире») |
| Кто на каком герое | 56 из 60 | — |

Настройки модели подобраны этим же бэктестом (`--args="--tune"`). Выборка маленькая: это ориентир, а не гарантия.

### Контрпики

Вкладка «Контрпики»: введите одного или двух их героев (например, хард и саппорт одной линии) и нашу позицию.
Три списка:
- **На линии** — кто чаще выигрывает линию против них: доля выигранных, ничейных и проигранных линий около 10-й
  минуты (по формуле STRATZ) и винрейт в этих играх;
- **По игре** — кто сильнее их за всю игру, независимо от линии;
- **Из наших героев** — герои нашего игрока на этой позиции, на которых он реально играет (5+ игр или 2+ за 2
  месяца), с числом игр, винрейтом и играми за 2 месяца.

В драфте, когда их герой на линии уже известен, а наш игрок этой позиции ещё без героя, над «Нам брать» появляется
«На линию»: 3 его героя, лучшие против них. В «Нам брать» линия добавлена к оценке и выводится первой причиной
(«линия ▲ vs Ember Spirit: 70% / 10%»), а герои, на которых игрок не играет, больше не предлагаются. Источники и
формулы — [ADR 0005](docs/decisions/0005-lane-stats.md).

### Иконки и оформление

Портреты и иконки героев и значки рангов — официальные картинки Valve, те же, что на Dotabuff и OpenDota (пути из
справочника героев OpenDota, CDN Steam). `./gradlew run` скачивает их в `data/img` (~11 МБ, без `--no-images`),
сайт отдаёт их сам — во время игры интернет не нужен. Если картинки нет, показываются инициалы героя.
Тема по умолчанию тёмная, переключатель ◐ в шапке.

### Вход по паролю

Если задана переменная окружения `SITE_PASSWORD`, сайт спрашивает общий пароль команды (вход запоминается на
устройстве на 30 дней). Без неё — открыт, это для локального запуска.

### Docker и сервер

```bash
cp .env.example .env              # SITE_PASSWORD, для сервера ещё DOMAIN
docker compose build
docker compose run --rm fetch     # обновить data/ из OpenDota
docker compose up -d              # сайт на http://localhost:8070
docker compose --profile https up -d   # на сервере: HTTPS через Caddy на https://$DOMAIN
```

Пошагово для сервера — [docs/deploy.md](docs/deploy.md), решения — [ADR 0004](docs/decisions/0004-server-deploy.md).

Сайт уже развёрнут на сервере команды, вход по общему паролю. Пока он работает по HTTP, без HTTPS. Что
осталось доработать после развёртывания — [замечания](docs/reviews/2026-10-16-deploy-review.md) и [план](docs/plans.md).
