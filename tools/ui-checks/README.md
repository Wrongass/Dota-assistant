# Проверки сайта в браузере

Сценарии в headless Chrome через DevTools Protocol, только стандартная библиотека Python. Нужны запущенный сайт
(`./gradlew web`) и Chrome по стандартному пути Windows (переменная `CHROME` в начале скрипта).

| Скрипт | Что проверяет |
|---|---|
| `draft_flow.py` | Драфт от начала: поиск, предупреждения и кнопки, списки не прыгают, защита от двойного клика, исправление хода, назначение, отмена, перезагрузка, карточка игрока |
| `draft_series.py` | Серия bo2/bo3: отдельный драфт на каждую карту, переключение, адрес, сброс одной карты |
| `draft_details.py` | Смена первого хода с подтверждением, индикатор исправления, отсчёт сброса, конец драфта, «Скопировать текстом» |
| `draft_url.py` | Соперник драфта в адресе, F5, неизвестный соперник и регистр |
| `site_misc.py` | Сортировка по рангу, время по часам браузера, меню «Соперники», названия вкладок, подписи банов, легенда, «Перечитать данные» |
| `meta_search.py` | Поиск на «Мете»: любой герой в «Все герои патча», русские имена и сленг, подписи пустых таблиц |
| `shared_draft.py` | Общий драфт по ссылке: создание, отправка своих ходов, подтягивание чужих |
| `ux_controls.py` | «Обозначения» на любой ширине, «ещё N / скрыть», подписи «показать / скрыть», поиск по-русски на слух, поиск под шапкой |
| `draft_sim.py` | Симуляция драфта: ходы соперника, отмена, оценка, правка позиций, «без подсказок» |
| `hero_search.py` | Сленг и порядок поиска героя (таблица из отчёта тестирования), раскладка, «Не нашёл», «Контрпики» |

Скрипты меняют драфт против SD Team в браузерном профиле `%TEMP%/dota-ui-checks`, данные сайта не трогают. Выход: строки
`OK`/`FAIL` и итог «N/M проверок прошли». Запускайте после любой правки JS: синтаксическая ошибка в `draft.js` роняет
весь экран драфта, а сборка Gradle её не замечает.
