## Как считаются оценки

- **Умение на герое (0–100)**: 40% — место среди всех игроков героя (OpenDota rankings, percent_rank);
  35% — винрейт с весом по давности (игра годичной давности весит ½), сглаженный к 50% весом 10 игр;
  25% — опыт (40 «свежих» игр = максимум). Турбо не учитывается.
- **Сила в мете (0–1)**: 60% — винрейт героя в пабах на ранге игрока ±1; 20% — винрейт на этой
  позиции в разобранных матчах патча (в основном про и высокий MMR); 20% — доля про-матчей с пиком/баном.
- **Пригодность в патче (0–100)** = поровну сила в мете и умение игрока.
- **▲ сильный / ▼ слабый** — винрейт в пабах на нужном ранге ≥ 52% / ≤ 48%.
- **Синергия пары** — винрейт пары в одной команде минус среднее базовых винрейтов героев;
  **контрпик** — винрейт героя против героя минус ожидаемый. Выборка: ~250 тыс. публичных матчей
  Legend+ текущего патча за последние ~15 часов (`data/meta/7.41/_sample.json`).

## Ограничения

- Позиции 1–5 в OpenDota напрямую нет: позиция героя оценена по разобранным матчам патча
  (4/5 — два последних по GPM в команде, 1/2/3 — по линии). Для редких героев может ошибаться.
- Детальная статистика (линия, предметы) есть только у разобранных матчей игроков.
- Патч берётся из справочника OpenDota; если он отстаёт от игры, мета будет за прошлый патч.
