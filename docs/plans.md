## Ближайшие доработки: отчёты тестирования 29.10

Отчёты: [капитанский](reviews/2026-10-29-qa-report.md) (ID BUG, UX, CNT, FEAT-01…13) и
[исследовательский](reviews/2026-10-29-exploratory-report.md) (ID E, SEC, FEAT-14…19). В исследовательском в начале есть
результат проверки агентом: что подтвердилось, что нет и почему.

**Сделать на сервере сейчас (без кода):**
1. Перекачать данные игроков: `docker compose run --rm fetch --refresh`, около 15 минут. Без `--refresh` уже скачанные
   игроки не обновляются, поэтому у нашей команды на сервере нет игр после первой выкладки (E-01, BUG-10).
2. Выгрузить линию: токен STRATZ теперь лежит в git (`config/tokens.env`), достаточно `git pull` и выгрузки (CNT-01, E-09).
3. Пересоздать контейнер сайта (`docker compose up -d --no-deps web`) и проверить в логе строку про сохранение
   состава.
4. Поставить обновление данных по cron с `--refresh` раз в сутки (давно в замечаниях по развёртыванию).

**Сначала, до ближайшей игры (P0):**
1. Сохранение состава на сервере. Сайт теперь пишет причину на странице и в лог, ждём лог.
2. Список рекомендаций не должен прыгать под курсором (BUG-01, BUG-11):
   - блоки на постоянных местах, текущий подсвечивается рамкой;
   - предупреждение поверх списка, а не со сдвигом;
   - защита от двойного клика 300–500 мс;
   - внесённый герой сразу пропадает из списков;
   - короткое сообщение «Внесено: бан Lion · Отменить».
3. Причины рекомендации видны сразу (UX-01): «контрит их X», «связка с Y», «пик-отказ» первыми в строке.
4. Серия bo2/bo3 (FEAT-01): отдельный драфт на каждую карту против одного соперника.
5. Без данных о линии капитан видит понятный текст, а не имя переменной окружения, пустая таблица скрыта (CNT-01).

**Потом (P1):**
- Безопасность (SEC-01, SEC-02):
  - домен и HTTPS, это заодно починит «Скопировать текстом» (BUG-06);
  - CSRF-токен в формах (cookie уже SameSite=Lax);
  - роли «капитан» и «игрок» позже (SEC-04).
- Сверка цифр между страницами:
  - ручные карты (BO2 1:1) на странице соперника, как на «Группе» (E-02);
  - названия команд и игроков из конфига вместо OpenDota, «BIM-TEAM» → BIM-TIM, Steam-ники → ники (E-03);
  - симметричная «Сыгранность» по объединению матчей пары (E-04);
  - «MMR (оценка)» убрать или переименовать, сортировать по рангу (E-05, E-17);
  - подпись «драфт не записан в OpenDota» и неполная сводка банов (E-11);
  - тест сверки: карты команды одинаковы на «Группе», «Турнире» и странице соперника, матрица симметрична.
- Угроза и умение учитывают давность и размер выборки: герой без игр за год не в топе угроз (E-06).
- Контрпики:
  - «авто» ставит против саппорта нашу лёгкую линию (E-07);
  - «Из наших героев» учитывает личный винрейт, минусовые не советует (CNT-03);
  - понятные колонки (CNT-05);
  - заголовок «Наша позиция 5 (Enaria) против Sniper» (E-21);
  - контрпики в драфте по клику на их героя (CNT-06).
- Ошибки и адреса:
  - страница ошибки в стиле сайта с кодировкой UTF-8;
  - 404 вместо 500 на `/player/<ник>` и длинный id;
  - id соперника без учёта регистра;
  - проверка `pos` (E-12);
  - смена соперника в драфте меняет адрес, неизвестный соперник с сообщением (E-13).
- Единый поиск героя для «Драфта», «Контрпиков» и «Меты»:
  - сленг (скай, тб, км, бб, шш, лс, рики, нага, тусик, войд спирит, шадоу);
  - порядок wr → Windranger, es → Earthshaker;
  - «не нашёл героя», взятые герои серым (BUG-09, CNT-02);
  - на «Мете» карточка героя, даже если его нет в топе (E-15).
- Предупреждения драфта:
  - кнопки «Забанить» и «Отмена», фокус в поиск (BUG-02);
  - «наш герой» только у свободных игроков (BUG-03);
  - пометка «⚠ наш» в «Нам банить» (BUG-04);
  - подтверждение смены первого хода (BUG-05).
- Понятность драфта:
  - легенда метрик (UX-02);
  - объяснимый порядок банов (UX-03);
  - угроза со страницы соперника и в драфте (UX-04).
- Позиции соперника по фактическим линиям и правка позиций прямо на драфте (UX-05). Поиск и лента всегда на экране,
  сетка героев сворачивается (UX-06).
- Состав и соперники из интерфейса:
  - замены прямо на драфте;
  - игрок не из конфига по ссылке Dotabuff;
  - новый соперник (FEAT-06, FEAT-07).
- Новое:
  - общий драфт по ссылке для всей команды (FEAT-14);
  - «план против факта» после серии (FEAT-16);
  - анализ состава, пары на двойные пики, флекс-герои (FEAT-03…05);
  - история драфтов (FEAT-02).
- Страницы игроков соперника и ссылки на игроков из всех таблиц (E-14, FEAT-18). Предупреждение об устаревшем
  `draft_plan.md`, дата и время следующей игры на главной.
