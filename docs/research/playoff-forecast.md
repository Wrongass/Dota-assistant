# Прогноз плей-офф: модели силы команд

Результат на сайте — страница «Прогноз» (`/forecast`), файл `analysis/forecast/playoff.md`. Считает
`tools/forecast/forecast.py` (Python, только stdlib), данные качает `tools/forecast/fetch.py`.

## Данные

- 171 карта Captains Mode из лиги на OpenDota: кто играл, позиция (`position_est`), кто выиграл. 47 команд.
- Текущий сезонный ранг всех 269 игроков этих карт из STRATZ (`data/forecast/ranks.json`).
- Пабы этих игроков за полгода из STRATZ (`data/forecast/pubs/`): средний ранг лобби, IMP и победа всех десяти
  игроков. Около 1000 запросов, 202 игрока с пабами (у остальных профиль скрыт или пабов нет).
- Составы на плей-офф — `config/players.yaml` без запасных.

## Модели

Все модели, кроме Эло, — логистическая регрессия на исход карты: P(A) = 1 / (1 + e^−(рейтинг A − рейтинг B)).

| Модель | Рейтинг команды |
|---|---|
| Звание | коэффициент × средний MMR званий пятёрки на этой карте |
| Лобби пабов | то же по среднему MMR лобби, где игрок играет пабы (свежие игры важнее, полураспад 60 дней) |
| Реальный уровень | лобби пабов + поправка за IMP сверх лобби и за винрейт; при малом числе игр тянется к званию |
| Звание + уровень | оба признака с отдельными весами |
| Только результаты | сила команды только по картам лиги (Брэдли — Терри), без рангов |
| Уровень + результаты, Звание + результаты | признак + поправка команды по картам лиги; поправка стянута к нулю (σ = 0.6) |
| Эло от уровня | реальный уровень + поправка, которая обновляется после каждой карты на 0.25 × (итог − прогноз) |
| Ансамбль | среднее трёх лучших по проверке |

Поправка команды учитывает силу соперников: победы над слабыми командами её почти не двигают. Поэтому лёгкая
группа «Звезды» сама по себе её рейтинг не завышает.

## Честная проверка

Карты каждого игрового дня предсказываются моделью, обученной только на картах до этого дня: 133 карты в 8 днях.

| Модель | Log-loss | Угадано карт |
|---|---|---|
| Уровень + результаты | 0.558 | 73% |
| Ансамбль | 0.559 | 74% |
| Эло от уровня | 0.559 | 73% |
| Реальный уровень | 0.568 | 73% |
| Лобби пабов | 0.568 | 74% |
| Звание + результаты (модель из чата 5.11) | 0.568 | 70% |
| Звание | 0.577 | 71% |
| Звание + уровень | 0.639 | 73% |
| Только результаты | 0.660 | 62% |
| Монетка | 0.693 | 50% |

Что получилось:
- Уровень лобби в пабах предсказывает лучше звания. Звание у тех, кто мало играет рейтинг, отстаёт от реальной игры.
- IMP сверх лобби не помог: лучший вес — 0 MMR за пункт IMP. Винрейт помогает чуть-чуть (10 MMR за п. п.).
  Лобби уже отражает скрытый рейтинг, а IMP шумный.
- Поправка по результатам лиги добавляет немного (0.568 → 0.558). По одним результатам без рангов модель
  слабая: у команд по 5–10 карт.
- Вес коров против саппортов: поровну лучше всего (×0.5 — 0.578, ×1 — 0.568, ×1.5 — 0.570, ×2 — 0.574).
- «Звание + уровень» переобучается: признаки почти совпадают, и на первых днях, где карт мало, веса уходят в разные стороны.

## Симуляция

- Сетка на двойное выбывание с сайта турнира: W1–W8 верхняя сетка и финал, L1–L6 нижняя.
  Перекрёстно: проигравший W6 играет в L3, проигравший W5 — в L4.
- Все серии BO3, в гранд-финале преимущества у победителя верхней сетки нет.
- 20 000 симуляций. В каждой берутся свои параметры модели из приближения Лапласа, так что неопределённость
  оценок (особенно поправок команд) попадает в итоговые шансы. Ансамбль в каждой симуляции берёт одну из трёх моделей.

## Ограничения

- Ранги текущие, пабы за полгода, в том числе после карт лиги. Для проверки это небольшая утечка.
- Уровень лобби у игрока, который часто играет в пати с более сильными или слабыми друзьями, смещён
  (например, у нашего пятого игрока лобби выше звания).
- Модель не видит драфт, пулы, форму в день игры и замены.

## Что можно попробовать ещё

- Рейтинг игрока по ролям (уровень на своей позиции, а не по всем играм).
- Линия в картах лиги (нетворс на 10-й минуте против визави) как отдельный признак.
- Пересчитать после каждого дня плей-офф: новые карты сразу уточнят поправки команд.
